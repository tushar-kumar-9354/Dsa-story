## 🌟 Key Features

### 1. 🎭 Step-by-Step Hinglish Stories & Real-Life Metaphors
Say goodbye to dry math jargon! Groq AI generates **custom, non-repetitive real-world analogies** tailored specifically to each problem:
- **Array / Search / Pairs** ➔ *Shaadi Matchmaker & Detective Investigation*
- **Stock Trading / Profit** ➔ *Share Bazaar Mandi Merchant*
- **Sliding Window** ➔ *Moving Bus Camera Zoom Lens*
- **Stack & Queue** ➔ *Cafeteria Plate Counter & ATM Line*

### 2. ⚡ Unforgettable Bottlenecks & 1-Sentence Memory Shortcuts
Every problem breaks down the **#1 Critical Trap** (off-by-one errors, TLE loops, overflow) along with a **1-sentence Hinglish Memory Trick** to remember the logic forever.

### 3. ☕🐍 Multi-Language Solution Code (Java & Python)
Choose your preferred programming language (`Java ☕`, `Python 🐍`, `C++ ⚡`, `JavaScript 💛`). Solution code comes pre-annotated with comments explicitly linking back to story steps!

### 4. 🇬🇧🇮🇳 Dual-Language Problem Descriptions
Toggle between **English** and **Hindi / Hinglish** problem statements with 1-click `[ 🇬🇧 EN | 🇮🇳 Hindi ]` tabs.

### 5. 🎯 Study-Focused Focus Mode & Fullscreen View Modes
- **Focus Mode 🎯:** Collapses side navigation for 100% deep concentration.
- **Fullscreen ⛶:** Open Code, Question, or Mindful Story in distraction-free fullscreen view with live editing support.

### 6. 🔒 Multi-User Account Isolation
Create private user accounts. Every user's code, story notes, and completion progress are **100% isolated** in local storage (`dsa_storybook_account_v2_${userId}`).

### 7. 📱 Mobile & Tablet Responsive
Fully responsive flex layout engineered for seamless study on desktops, iPads, and mobile phones.

## 🚀 Quick Start Guide

### 1. Clone the Repository
```bash
git clone https://github.com/tushar-kumar-9354/Dsa-story.git
cd Dsa-story
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Set Up Environment Variables
Create a `.env` file in the project root:
```env
VITE_GROQ_API_KEY=your_groq_api_key_here
```

### 4. Run Development Server
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

---

## 📦 Production Build & Vercel Deployment

### Build Locally
```bash
npm run build
```

### Deploy to Vercel in 1 Minute
```bash
npx vercel
```
*Note: `vercel.json` is pre-configured for SPA routing.*
